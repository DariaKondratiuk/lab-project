# Лабораторна робота №2. Основи мови Go

**Мета роботи**: набуття практичних навичок встановлення та налаштування
середовища для розробки на Go, компіляції та виконання програм, а також розуміння
основних механізмів роботи мови.

**Варіант 5. Автопарк та пошук найдорожчого авто**

   Створіть структуру Brand, що містить:
*    Назву бренду
*    Країну виробника
*    Структуру Car, яка містить:
*    Марку (Brand)
*    Модель
*    Ціну
*    Рік випуску
   
Реалізуйте метод, що визначає, чи авто старше 10 років. Використайте slice для
збереження авто та реалізуйте функцію пошуку найдорожчого автомобіля. Map що буде
зберігати автомобілі по країнах виробників.
